# Security Policy

## Supported Versions

Only the latest release and `main` branch of `agy-vitals` are supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in `agy-vitals`, please report it privately rather than opening a public issue:

- Use GitHub's private vulnerability reporting feature (**Security → Advisories → Report a vulnerability**) on [2fa0/agy-vitals](https://github.com/2fa0/agy-vitals/security/advisories/new).
- Include steps to reproduce, affected version/commit, and potential impact.

We will acknowledge receipt promptly and work on a fix before any public disclosure.
